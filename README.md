# EatGood（吃好）

EatGood 是一个面向家庭日常饮食决策与烹饪执行的健康饮食产品。产品以菜谱内容为基础，结合个人口味、忌口、家庭情况、地区与时令信息，帮助用户完成从“今天吃什么”到“把菜端上桌”的完整过程。

当前处于产品定义阶段，技术栈尚未确定。首要目标是验证以下闭环：

`了解用户 → 推荐菜单 → 安排一日三餐 → 生成采购清单 → 引导烹饪 → 收集反馈 → 改进推荐`

阶段功能、范围边界、风险与验收门槛见 [产品阶段规划](docs/product-roadmap.md)。

## 当前原则

- 先验证家庭用户的日常饮食闭环，再建设供货和服务市场。
- 过敏与明确忌口属于硬约束，不允许被推荐算法降级处理。
- 推荐必须可解释、可替换、可纠错，不做不可控的“黑盒菜单”。
- 烹饪教程既要支持逐步跟做，也要为并行备菜、等待和汇合步骤预留结构化模型。
- 食品安全提示、过敏风险提示和个人数据导出等基础保障不作为付费门槛。
